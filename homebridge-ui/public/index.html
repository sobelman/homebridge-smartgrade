SmartGrade login התחברות לדילאור (SmartGrade)

⚠️ The vendor login lasts 30 days and has no refresh. About once a month, come back here, press “Send SMS” and enter the new code. Homebridge restarts the plugin with the new token. ⚠️ ההתחברות של היצרן תקפה ל-30 יום בלבד ואין חידוש אוטומטי. פעם בחודש בערך חזרו לכאן, לחצו "שלח SMS" והזינו את הקוד החדש.

Devices מכשירים

Read-only information from the cloud. Timers set in the Dealor app keep running in the cloud; this plugin only shows them. מידע לקריאה בלבד. טיימרים שהוגדרו באפליקציה ממשיכים לרוץ בענן; הפלאגין רק מציג אותם.
